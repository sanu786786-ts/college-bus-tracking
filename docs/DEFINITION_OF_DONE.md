# Definition of Done (team-wide) — CampusBus

A story is **Done** only when ALL are true:
1. Code written, committed to GitHub with the Jira key in the message (e.g. `CBT-4 add route list`).
2. Reviewed by at least one other team member (pull request or pair check).
3. Acceptance criteria of the story are met (see story description in Jira).
4. Related test cases in `docs/TEST_CASES.md` executed and passed.
5. Input validation and error messages in place; no console errors.
6. Works end-to-end with sample data in the running application.
7. README / docs updated.
8. Demonstrated in the Sprint Review and card moved to **Done** on the board.

**Acceptance criteria vs DoD:** acceptance criteria belong to one story; the DoD is the quality bar for every story.

## Workflow (board columns)
To Do → In Progress → Testing → Done
